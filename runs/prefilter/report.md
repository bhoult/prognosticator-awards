# Pre-filter tuning report

Decided before the run: use the filter only if some setting keeps at least 95% of the models' speculative claims (all models combined, and Sonnet's alone) on held-out texts, while keeping at most 70% of a random sample of the sci-fi library. Otherwise drop it.

Gold set: 37 chunks from 17 texts. Held-out numbers are leave-one-text-out: each text is filtered with a word list learned from the other texts. Library sample: 200 random sci-fi books and 60 other books (seed 2026), filtered with the list learned from all gold texts.

"Claims" = speculative claims verified for any of Haiku, Sonnet and Opus, near-duplicates merged (1230). "Known" = the answer key's realized and failed predictions.
